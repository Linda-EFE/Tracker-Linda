# Tracker-Linda – Ernährungscoach

Eine kleine Web-App im Handy-Look: Sie führt dich in 13 Fragen durch dein Profil, rechnet daraus deinen Kalorien- und Makroplan (Mifflin-St Jeor, Aktivitätsfaktor, Leitplanken für Mindestkalorien und Abnahmetempo) und erstellt am Ende einen Anweisungsblock für deine Claude-Projektanweisungen.

Alles steckt in einer Datei: `index.html`. Keine Installation, kein Server nötig. Antworten werden nur lokal im Browser gespeichert.

## Im Browser öffnen (GitHub Pages)

1. Im Repository auf **Settings → Pages** gehen.
2. Unter **Build and deployment** bei *Source* „Deploy from a branch“ wählen.
3. Branch auswählen (z. B. `main` nach dem Mergen) und Ordner `/ (root)`, dann **Save**.
4. Nach ein bis zwei Minuten ist die App erreichbar unter
   `https://linda-efe.github.io/Tracker-Linda/`

Lokal geht es auch: `index.html` einfach doppelt anklicken.
